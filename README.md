# 🎵 レッスン記録管理システム

音大生のための包括的なレッスン記録管理Webアプリケーション

## ✨ 特徴

- **完全オフライン対応**: すべてのデータはブラウザのIndexedDBに保存され、インターネット接続なしで動作
- **マルチメディア対応**: 音声ファイル、画像（レッスンノート・図解）を一元管理
- **レスポンシブデザイン**: スマートフォン、タブレット、デスクトップに最適化
- **直感的なUI/UX**: モダンで使いやすいインターフェース
- **データエクスポート/インポート**: JSON形式でデータのバックアップと復元が可能

## 📋 主な機能

### レッスン記録の管理
- ✅ レッスン記録の追加・編集・削除
- ✅ 日付と先生名による管理
- ✅ 要約テキストの記録
- ⭐ **評価システム**: 5段階の星評価でレッスンの満足度を記録
- 💭 **感想・振り返り**: レッスンの感想や気づきを詳細に記録
- 📝 **練習課題メモ**: 次回までの練習課題を管理

### マルチメディア機能
- 🎵 **音声記録**: レッスン中の演奏や指導内容を録音
- 📝 **レッスンノート画像**: 手書きメモや楽譜のスキャン画像を保存（複数枚対応）
- 📄 **PDFファイル**: レッスンノートをPDF形式で保存・閲覧（複数ファイル対応）
- 📊 **図解画像**: 練習方法や理論の図解を保存（複数枚対応）
- 🔊 **ブラウザ内音声再生**: 保存した音声をその場で再生
- 🖼️ **画像ギャラリー**: 画像をクリックで拡大表示、前後の画像に移動可能

### マルチデバイス同期（オプション）
- 📱 **デバイス間同期**: iPhone、iPad、PCなど複数のデバイス間でデータを自動同期
- 🔐 **セキュアな認証**: メール/パスワードによる安全なユーザー認証
- 🌐 **リアルタイム同期**: デバイス間でリアルタイムにデータが同期
- ⚡ **オフライン対応**: インターネット接続がなくても動作し、オンライン時に自動同期

### 検索・フィルター機能
- 🔍 テキスト検索（先生名、要約テキスト）
- 👨‍🏫 先生名でのフィルタリング
- 📅 日付での並び替え（新しい順/古い順）
- 🔤 先生名での並び替え

### データ管理
- 💾 **エクスポート**: すべてのレッスン記録をJSON形式で保存
- 📥 **インポート**: 過去のデータを復元

## 🚀 使い方

### 起動方法

1. `index.html`をWebブラウザで開く
2. モダンなブラウザ（Chrome、Firefox、Safari、Edgeの最新版）を推奨
3. **ローカルモード**: そのまま使用可能（デバイス間同期なし）
4. **同期モード**: Firebase設定後にログインして使用（デバイス間同期あり）

### マルチデバイス同期の設定（オプション）

マルチデバイス同期機能を使用する場合は、以下の手順でFirebaseを設定してください。

#### 1. Firebaseプロジェクトの作成

1. [Firebase Console](https://console.firebase.google.com/) にアクセス
2. 「プロジェクトを追加」をクリック
3. プロジェクト名を入力（例: "lesson-records"）
4. Google Analyticsは任意（スキップ可）
5. プロジェクトを作成

#### 2. Firestoreデータベースの有効化

1. Firebaseプロジェクトのコンソールで「Firestore Database」を選択
2. 「データベースを作成」をクリック
3. **テストモードで開始**を選択（後でルールを設定可能）
4. ロケーションを選択（例: asia-northeast1）

#### 3. 認証の有効化

1. Firebaseプロジェクトのコンソールで「Authentication」を選択
2. 「始める」をクリック
3. 「Sign-in method」タブを選択
4. 「メール/パスワード」を有効化

#### 4. Webアプリの設定情報を取得

1. Firebaseプロジェクトのコンソールで、歯車アイコン ⚙️ > 「プロジェクトの設定」を選択
2. 「全般」タブの下部「マイアプリ」セクションで、「</> Web」アイコンをクリック
3. アプリのニックネームを入力（例: "lesson-records-web"）
4. 「Firebase Hosting」は不要（チェック不要）
5. 「アプリを登録」をクリック
6. 表示される設定情報（firebaseConfig）をコピー

#### 5. アプリケーションに設定を適用

1. プロジェクトフォルダ内の`firebase-config.js`ファイルを開く
2. 以下の値を、取得した設定情報に置き換える:
   ```javascript
   const firebaseConfig = {
       apiKey: "YOUR_API_KEY_HERE",              // ← 取得した値に置き換え
       authDomain: "YOUR_PROJECT_ID.firebaseapp.com",
       projectId: "YOUR_PROJECT_ID",
       storageBucket: "YOUR_PROJECT_ID.appspot.com",
       messagingSenderId: "YOUR_MESSAGING_SENDER_ID",
       appId: "YOUR_APP_ID"
   };
   ```
3. `FIREBASE_ENABLED`を`true`に変更:
   ```javascript
   const FIREBASE_ENABLED = true;
   ```
4. ファイルを保存

#### 6. アプリケーションの使用

1. ブラウザで`index.html`を開く（またはリロード）
2. ヘッダーの「ログイン」ボタンをクリック
3. 「アカウントを作成」を選択
4. メールアドレスとパスワード（8文字以上）を入力
5. アカウントを作成
6. 他のデバイスでも同じアカウントでログインすると、データが同期されます

#### セキュリティルールの設定（推奨）

本番環境で使用する場合は、Firestoreのセキュリティルールを設定してください。

1. Firebaseコンソールで「Firestore Database」>「ルール」を選択
2. 以下のルールを適用:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // ユーザーは自分のデータのみアクセス可能
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```

3. 「公開」をクリック

### レッスン記録の追加

1. 「新規追加」ボタンをクリック
2. 以下の情報を入力:
   - **レッスン日**（必須）
   - **先生の名前**（必須）
   - **要約テキスト**（必須）
   - **音声ファイル**（任意）
   - **レッスンノート画像**（任意・複数可）
   - **図解画像**（任意・複数可）
3. 「保存」ボタンをクリック

### ファイルのアップロード方法

- **クリック**: ファイル選択エリアをクリックしてファイルを選択
- **ドラッグ&ドロップ**: ファイルをエリアにドラッグ&ドロップ

#### 対応ファイル形式
- **音声**: MP3, WAV, M4A, OGG
- **画像**: JPG, PNG, GIF, WEBP
- **PDF**: PDF形式のドキュメント

### レッスン記録の閲覧

1. 一覧からレッスン記録のカードをクリック
2. 詳細ページで以下を確認:
   - レッスン日と先生名
   - 要約テキスト
   - 音声再生（音声がある場合）
   - レッスンノート画像
   - 図解画像

### レッスン記録の編集

1. 詳細ページで「編集」ボタンをクリック
2. 情報を修正
3. 「保存」ボタンをクリック

### レッスン記録の削除

1. 詳細ページで「削除」ボタンをクリック
2. 確認ダイアログで「削除する」をクリック

### 検索とフィルター

- **検索ボックス**: 先生名や要約テキストでリアルタイム検索
- **先生フィルター**: 特定の先生のレッスンのみを表示
- **並び順**: 日付順または先生名順で並び替え

### データのバックアップ

1. 「エクスポート」ボタンをクリック
2. JSON形式のファイルがダウンロードされる
3. このファイルを安全な場所に保管

### データの復元

1. 「インポート」ボタンをクリック
2. 以前エクスポートしたJSONファイルを選択
3. データが自動的にインポートされる

## 🛠️ 技術仕様

### フロントエンド
- **HTML5**: セマンティックマークアップ
- **CSS3**: カスタムプロパティ、Flexbox、Grid Layout
- **JavaScript (ES6+)**: Vanilla JavaScript（フレームワーク不要）

### データストレージ
- **IndexedDB**: ブラウザ内データベース
  - レッスンメタデータ
  - Base64エンコードされた音声・画像ファイル

### アーキテクチャ
- **シングルページアプリケーション（SPA）**
- **オブジェクト指向設計**
  - `LessonDB`: データベース操作
  - `AppState`: アプリケーション状態管理
  - `UIController`: UI制御とイベント処理

### 特徴的な実装
- ドラッグ&ドロップによるファイルアップロード
- モーダルウィンドウによる画像プレビュー
- トースト通知によるユーザーフィードバック
- レスポンシブグリッドレイアウト

## 💡 使用例

### 音大生の日常的な使い方

1. **レッスン後すぐに記録**
   - レッスン直後にスマートフォンから記録を追加
   - 演奏の録音をアップロード
   - 先生の書いた図解をカメラで撮影してアップロード

2. **復習時に活用**
   - 先生別にレッスンを検索
   - 過去の音声を聴き直して練習
   - レッスンノートを見返して重要ポイントを確認

3. **定期的なバックアップ**
   - 月末にデータをエクスポート
   - クラウドストレージに保存

## 🔒 プライバシーとセキュリティ

- **ローカルストレージ**: すべてのデータはブラウザ内に保存され、外部サーバーには送信されません
- **オフライン動作**: インターネット接続不要
- **データ所有権**: ユーザーが完全にデータを管理

## 🎨 カスタマイズ

CSS変数を使用しているため、`styles.css`の`:root`セクションを編集することで、簡単にカラーテーマをカスタマイズできます。

```css
:root {
    --color-primary: #6366f1;
    --color-secondary: #8b5cf6;
    --color-accent: #ec4899;
    /* その他のカラー設定 */
}
```
